# 🏠 LOCAL FIT

**공공데이터 기반 수도권 지역 분석·추천 플랫폼**

사용자가 조건을 설정하면, 공공데이터를 수집·가공해 조건에 맞는 지역을 점수화하여 추천하는 서비스입니다.

---

## 📖 프로젝트 소개

기존 부동산/지역 정보 서비스가 단순 검색·필터링에 그치는 것과 달리, LOCAL FIT은 **공공데이터를 직접 수집·정제해 지역별 지표를 만들고**, 사용자가 등록한 관심지역을 **시군구/시도/수도권 3개 계층에서 독립적으로 평가**하여 "이 지역이 어느 정도 위치인지"를 정직하게 보여주는 것을 목표로 합니다.

단순히 외부 API를 호출해서 보여주는 것이 아니라, **수집 → 저장 → 통계 → 정규화 → 캐싱**으로 이어지는 데이터 파이프라인을 직접 설계하는 데 중점을 뒀습니다.

## 🏗 아키텍처

외부 공공데이터 API를 사용자 요청 시점에 직접 호출하지 않고, **수집 계층과 서비스 계층을 분리**했습니다. 사용자 요청은 항상 내부 DB/캐시만 조회하도록 하여, 외부 API의 응답 지연이나 장애가 서비스 품질에 직접 영향을 주지 않도록 설계했습니다.

```
[공공데이터 API]
       │  배치 수집 (수동 트리거)
       ▼
    MySQL 저장
       │
       ▼
  통계/집계 (JPQL 집계 쿼리)
       │
       ▼
 추천 점수 계산 (정규화 + Redis 캐싱)
       │
       ▼
     REST API  ──▶  클라이언트
```
